# NIRVO Open World

A browser-based 3D Kerala-inspired life simulator prototype built with Vite and Three.js.

## Current build — World 01
- Procedurally generated Kerala-inspired town map
- 20 individual unnamed houses
- Main roads, junctions, sidewalks and streetlights
- Bus stand and buses, hospital, police station, school, market and community hall
- Temple, church and mosque
- River, bridge, fishing jetty, boats and paddy fields
- Coconut palms and tropical greenery
- Third-person character movement, mouse camera look, keyboard and mobile touch controls

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Controls
- WASD / arrow keys: move
- Shift: run
- Drag mouse / touch: rotate camera
- On mobile, use the on-screen directional pad
